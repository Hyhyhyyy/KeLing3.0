# Support

Use Issues for reproducible bugs and Discussions for product ideas and setup questions.
Include the affected client, commit/version, operating system, and steps using synthetic
data. Never upload an account token, `.env` file, database, keystore, or personal note.

KeLing is currently a preview and has no guaranteed uptime or response time. Security
problems belong in the private channel described in [SECURITY.md](SECURITY.md).
